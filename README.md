# ПроектоСфера — сайт для GitHub Pages

Статическая копия выставки: `index.html` (3D-павильон), `catalog.html` (каталог), `privacy.html` (правила и конфиденциальность).
Публикация: загрузите содержимое этой папки в корень репозитория → Settings → Pages → ветка `main`, папка `/`.
Стенды в `data/stands.js` — демонстрационные (выдуманные команды, «Демо-школа»). Реальные стенды добавляются только с согласия авторов и родителей, без ФИО.
