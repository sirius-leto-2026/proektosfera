# ПроектоСфера — сайт для GitHub Pages

Статическая копия выставки без сборки и npm: `index.html` (3D-павильон на A-Frame/three.js),
`catalog.html` (каталог-список для слабых устройств и чтения с экрана), `present.html` (демо-презентация стенда),
`product.html` (демо-продукт проекта), `privacy.html` (правила и конфиденциальность).
Публикация: загрузите содержимое этой папки в корень репозитория → Settings → Pages → ветка `main`, папка `/`.

- Стенды и залы — в `data/stands.js`; число проектов и направлений на страницах считается из этих данных.
- Постоянная ссылка на стенд: `index.html#stand=s01` — открывает карточку и подводит камеру к стенду.
  Кнопка «Поделиться» в карточке копирует такую ссылку.
- Общие стили — `css/style.css`, карточка/статистика/ссылки — `js/common.js`.
- Обложка для соцсетей — `cover.png` (1200×630), иконка — `favicon.svg`. OG-теги и `theme-color` есть на всех страницах.

Стенды в `data/stands.js` — демонстрационные (выдуманные команды, «Демо-школа»). Реальные стенды добавляются только
с согласия авторов и родителей, без ФИО.
